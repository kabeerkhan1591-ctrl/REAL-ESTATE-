
🏡 Sterling & Co. — Real Estate Platform
A sleek, modern real estate website for browsing premium properties, connecting with agents, and managing listings.
✨ Features
Table
Feature	Description
🎬 Hero Video	Cinematic landing with floating price tags & agency stats
🔍 Smart Search	Filter by Buy/Rent, location, property type, price & bedrooms
🏠 Property Cards	12 curated listings with images, specs & favorite buttons
💬 WhatsApp Tours	One-click "Request a Tour" opens WhatsApp with pre-filled property details
❤️ Favorites	Save properties to a slide-out panel
🧮 Mortgage Calculator	Built-in payment estimator inside every property modal
👤 Agent Profiles	Meet the team with contact info
🔐 Agent Portal	Login dashboard to add, edit & delete listings (demo: any email + demo123)
📱 Responsive	Works on mobile, tablet & desktop
